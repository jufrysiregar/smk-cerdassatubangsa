Tentang Jurusan RPL

Rekayasa Perangkat Lunak (RPL) adalah jurusan yang mendalami cara-cara pengembangan perangkat lunak, meliputi pembuatan, pemeliharaan, manajemen kualitas, dan manajemen organisasi pembangunan perangkat lunak. Siswa diajarkan cara membuat aplikasi berbasis web, mobile (smartphone), maupun sistem desktop yang fungsional.

Logika & Algoritma Pemrograman Fullstack Web Development Mobile App Development Database Architecture & QA Testing

Silabus Kegiatan Belajar Mengajar (KBM)

Kurikulum vokasi berbasis industri software engineering global dengan pembiasaan standar clean code dan git workflow.

01

Pemrograman Dasar

Memahami logika pemrograman, algoritma dasar, flowchart, serta penggunaan bahasa pemrograman awal (seperti Python atau JavaScript dasar).

02

Pemrograman Berorientasi Objek (PBO)

Mempelajari konsep kelas, objek, pewarisan, dan enkapsulasi dalam bahasa pemrograman populer (Java/C++).

03

Basis Data (Database)

Perancangan tabel basis data, relasi antar data, serta penggunaan bahasa SQL (MySQL/PostgreSQL) untuk pengolahan data aplikasi.

04

Pemrograman Web & Perangkat Bergerak (Mobile)

Pembuatan website interaktif (HTML, CSS, JavaScript, PHP/Node.js) serta dasar pembuatan aplikasi Android (Flutter/Kotlin).

05

Pengujian Perangkat Lunak (QA/Testing) & Git

Pengujian fungsionalitas program (bug testing) dan kolaborasi kode menggunakan sistem kontrol versi (Git/GitHub).

Peluang / Prospek Karir

Lulusan RPL SMK Cerdas Satu Bangsa memiliki prospek kerja luas di industri startup, software house, tech company multinasional, dan perbankan digital.

Web Engineering

Junior Web Developer / Programmer

Membangun website responsif, REST API backend, dan antarmuka web interaktif untuk berbagai sektor bisnis.

Mobile Engineering

Junior Mobile App Developer

Mengembangkan aplikasi smartphone Android dan iOS berbasis Flutter atau native untuk kebutuhan pengguna modern.

Quality Assurance

QA (Quality Assurance) Tester Junior

Menjalankan pengujian fungsionalitas fitur aplikasi, mendeteksi error/bug tampilan, dan mencatat laporan evaluasi mutu sistem.

Data Management

Database Support / Data Entry Administrator

Mengelola integritas relasi tabel basis data perusahaan, optimasi query SQL, serta perawatan backup data digital.

Technical Operation

Software Documentation & Support Staff

Menyusun manual teknis dan dokumentasi rilis fitur software untuk kemudahan kolaborasi tim developer dan pengguna.

Referensi Jurusan & Fakultas Kuliah Lanjutan

Lulusan RPL yang ingin memperdalam ilmu sains data dan rekayasa perangkat lunak lanjutan dapat memilih fakultas berikut:

Fakultas Ilmu Komputer / Fakultas Teknologi Informasi

Program studi lanjutan yang sangat linier dengan penguasaan koding, arsitektur software, dan teknologi kecerdasan buatan:

S1 Rekayasa Perangkat Lunak (Software Engineering) Mendalami metodologi pengembangan software skala besar, cloud native, microservices, dan arsitektur enterprise.
S1 Teknik Informatika Fokus pada rekayasa algoritma tingkat tinggi, kecerdasan buatan (AI), machine learning, dan komputasi sains.
S1 Ilmu Komputer (Computer Science) Mendalami fondasi teoretis komputasi, struktur data kompleks, kompilator, dan keamanan siber lanjutan.
S1 Sistem Informasi / Bisnis Digital Menghubungkan arsitektur software dan database dengan analisis kebutuhan proses bisnis serta transformasi digital perusahaan.
